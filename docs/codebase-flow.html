Push, then poll

Agents register once, then send resource heartbeats after each 2-second sleep. React loads immediately and polls the Hub every 3 seconds. The Hub does not poll agents for resources.

Backend ahead of the UI

Docker sessions, node selection, and terminal attach are implemented on the backend. App.tsx currently renders node cards only; it has no session controls or terminal client.

Memory is the live source

The Hub serves its in-memory maps. SQLite receives agent upserts, but there is no startup reload or stale-status writeback. Session maps are not persisted or reconciled with Docker.
